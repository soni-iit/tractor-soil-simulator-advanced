# tractor-soil-simulator-advanced
Advanced, offline, single-file Tractor–Soil Interaction Simulator: field-calibrated Brixius/ASABE traction, 2WD/MFWD/4WD tractor library, bias &amp; radial tyres, soil texture–moisture–cone-index inputs, subsoil stress &amp; compaction (SCSI), Bekker–Wong cross-check, validation against published field data.
